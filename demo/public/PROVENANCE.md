# Procedência da cena

`vendor/cena.js` e `vendor/sprites/heroi.png` vieram de `D:/code/betaki/backend-gateway/src/HouseGateway.Api/wwwroot/play/crash/`, o Decolagem indicado pelo usuário. O JavaScript recebeu somente a formatação do projeto; a arte foi copiada sem edição. O documento de origem `docs/games/05-heroi-decolagem.md` registra o sprite como arte gerada para a casa, sem arte de terceiro.

A cena desenha fases, partículas e avião e não decide pagamentos. A integração HTTP, a mesa de demonstração e a interface de evidências são específicas deste challenge. A carteira, as sessões, os tokens e os serviços .NET do gateway não foram copiados. O gateway original permanece intacto; nenhum caminho externo é necessário para executar a demo.
